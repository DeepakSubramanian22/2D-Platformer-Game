# SuperWomen 2D Adventure

## Overview

SuperWomen 2D Adventure is a classic 2D platformer inspired by games like Super Mario. Players control SuperWomen as she runs through challenging levels, collecting coins while avoiding dangerous baby crocodiles. The objective is to gather coins, survive enemy encounters, and reach the end of each level to progress further.

---

## Gameplay

* Control SuperWomen through a side-scrolling platformer environment.
* Collect coins scattered throughout the level.
* Avoid baby crocodiles that patrol the area.
* Reach the level exit to advance to the next stage.
* If SuperWomen is bitten by a baby crocodile, the game ends.

---

## Objective

Your mission is to guide SuperWomen safely through each level by:

1. Collecting coins.
2. Avoiding baby crocodiles.
3. Reaching the level exit.
4. Progressing through increasingly challenging levels.

Be careful! A single crocodile bite will end the game.
